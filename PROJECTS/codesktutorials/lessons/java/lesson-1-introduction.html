Introduction to Java

5 lessons~15 minhas assessment
Java

Java is a popular programming language, created in 1995. It is owned by Oracle, and more than 3 billion devices run Java. It is used for:

  • Mobile applications (especially Android apps)
  • Desktop applications
  • Web applications
  • Web servers and application servers
  • Game consoles, plus many other uses

Your first Java program

When you write a Java program it must be inside a class, and the program always starts inside the main method. This program prints Hello World to the console:

public class MyClass {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}

System.out and the difference between println and print

System.out.println() prints a line of text and then adds a new line, while System.out.print() prints the text without moving to a new line:

System.out.println("I am learning Java.");
System.out.println("It is awesome!");

Java comments

Comments can be used to explain Java code and to make it more readable. Single-line comments start with two forward slashes //, and multi-line comments start with /* and end with */:

// This is a single-line comment

/* This is a
   multi-line comment */
System.out.println("Hello World"); // comments can also go at the end of a line
Note
Did you know?
  • Java was created by James Gosling at Sun Microsystems and released in 1995.
  • Java is platform-independent — "write once, run anywhere".
  • The main method is the entry point of every Java application.
